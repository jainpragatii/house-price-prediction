# House Price Prediction

This project predicts house sale prices using the Kaggle House Prices: Advanced Regression Techniques dataset.

## Model Used
- Random Forest Regressor
- 200 estimators
- Random state: 42

## Data Processing
- Loaded the Kaggle House Prices dataset
- Checked missing values
- Handled missing values
- Converted categorical features into numerical values
- Prepared training and testing datasets

## Result

Kaggle Score: **0.14677**

The predictions were saved in `submission.csv` and successfully submitted to Kaggle.

## Tools & Technologies

- Python
- Pandas
- Scikit-learn
- Random Forest Regression
- Kaggle
- Jupyter Notebook

## Dataset

House Prices: Advanced Regression Techniques — Kaggle.

## Project Outcome

The trained model successfully predicted house prices for the test dataset and generated a valid Kaggle submission.
